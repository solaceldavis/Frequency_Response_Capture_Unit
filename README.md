# Frequency_Response_Capture_Unit
This is the code base for all the microcontroller programming and processing of the data upon capture.

# ESP 32 Frequency Capture
The program takes the voltage from an electret microphone capsule and saves those values to a csv file. This csv file is downloadable from a web page hosted of the ESP 32.

# RP2040 Speaker Driver
The program drives a 4 ohm speaker with the RP 2040 when one of the pins is driven high. There is a slight delay to allow the ESP 32 Frequency Capture to begin capturing.
